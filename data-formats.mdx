One of Serde's core design decisions is the clean separation between data structures and data formats. The `serde` crate defines the `Serialize`, `Deserialize`, `Serializer`, and `Deserializer` traits, but it does not bundle any concrete format. Format crates implement the `Serializer` and `Deserializer` traits to teach Serde how to encode and decode data in a specific representation. Because these two halves interact only through Serde's trait boundary, any data structure that derives or implements `Serialize`/`Deserialize` works automatically with every format crate — with no changes to the struct or enum itself.

## How to use any format

Every format crate follows the same basic pattern. The crate provides top-level functions (commonly `to_string` / `from_str`, `to_vec` / `from_slice`, or `to_writer` / `from_reader` depending on whether the format is text or binary) that accept any type implementing `Serialize` or `Deserialize`. Your data types never need to change between formats.

```rust
use serde::{Deserialize, Serialize};

#[derive(Serialize, Deserialize, Debug)]
struct Config {
    host: String,
    port: u16,
    debug: bool,
}
```

Because `Config` derives `Serialize` and `Deserialize`, it works with every format without modification:

```rust
fn main() {
    let config = Config {
        host: "localhost".to_string(),
        port: 8080,
        debug: true,
    };

    // --- JSON ---
    let json = serde_json::to_string(&config).unwrap();
    println!("JSON:    {}", json);
    // {"host":"localhost","port":8080,"debug":true}

    let from_json: Config = serde_json::from_str(&json).unwrap();
    println!("from JSON:  {:?}", from_json);

    // --- TOML ---
    let toml_str = toml::to_string(&config).unwrap();
    println!("TOML:\n{}", toml_str);
    // host = "localhost"
    // port = 8080
    // debug = true

    let from_toml: Config = toml::from_str(&toml_str).unwrap();
    println!("from TOML:  {:?}", from_toml);

    // --- YAML ---
    let yaml = serde_yaml::to_string(&config).unwrap();
    println!("YAML:\n{}", yaml);

    let from_yaml: Config = serde_yaml::from_str(&yaml).unwrap();
    println!("from YAML:  {:?}", from_yaml);
}
```

The corresponding `Cargo.toml` for the example above:

```toml
[dependencies]
serde      = { version = "1.0", features = ["derive"] }
serde_json = "1.0"
toml       = "0.8"
serde-yaml = "0.9"
```

<Note>
  Format crates that are listed as **serialization only** or **deserialization only** implement only one half of the `Serializer`/`Deserializer` pair. You can still derive both `Serialize` and `Deserialize` on your types — you simply cannot use the direction that the crate does not support.
</Note>
