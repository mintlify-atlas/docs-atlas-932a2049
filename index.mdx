Serde is Rust's de facto serialization framework. It lets any data structure that implements `Serialize` or `Deserialize` work seamlessly with any data format — from JSON to TOML to MessagePack — with zero runtime reflection and compiler-optimized performance.

## What is Serde?

Serde is built on Rust's trait system. A type that implements `Serialize` knows how to describe itself to any serializer. A type that implements `Deserialize` knows how to reconstruct itself from any deserializer. The data format crate (like `serde_json`) provides the `Serializer` and `Deserializer` implementations.

This separation means you write serialization logic once — and it works with every format, forever.

<Steps>
  <Step title="Add serde to Cargo.toml">
    Add `serde` with the `derive` feature, plus a format crate like `serde_json`.
  </Step>
  <Step title="Derive Serialize and Deserialize">
    Annotate your structs and enums with `#[derive(Serialize, Deserialize)]` — no boilerplate required.
  </Step>
  <Step title="Serialize and deserialize">
    Call functions from your chosen format crate, such as `serde_json::to_string` and `serde_json::from_str`.
  </Step>
  <Step title="Customize with attributes">
    Use `#[serde(...)]` attributes to rename fields, skip values, apply defaults, and control enum representations.
  </Step>
</Steps>
